# 🇮🇳 Indian Culture Mini Project

This is a small web project developed using **PHP, HTML, and CSS**.  
The website showcases **Indian culture**, including traditions, festivals, heritage, and diversity.

## 🌸 Features
- Indian festivals and traditions section
- Simple and clean UI
- PHP-based backend structure
- Responsive design using CSS

## 🛠 Technologies Used
- PHP
- HTML
- CSS

## 🎯 Objective
- Learn PHP basics
- Practice frontend design
- Create a culture-based mini project
- Build a portfolio-ready web application

## 📁 Project Type
Mini Project / Beginner Level
